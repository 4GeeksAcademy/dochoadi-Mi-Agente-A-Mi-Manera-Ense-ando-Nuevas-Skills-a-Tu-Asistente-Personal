# Skill: Diario de aprendizaje

## Descripción
A partir de unos pocos puntos sobre lo que aprendí hoy, formatea y añade una entrada estructurada a un Google Doc que uso como diario personal de aprendizaje.

## Cuándo usar
Cuando diga "hoy aprendí...", "anota esto en mi diario de aprendizaje", "añade esto a mi diario" o active esta skill explícitamente.

## Prerrequisitos
- Google Docs disponible vía Zapier (cuenta `dodochoadiaz@gmail.com`, ver `TOOLS.md`).
- Si no existe todavía un Doc de diario, créalo la primera vez con el título "Diario de aprendizaje — Daniel Ochoa" y pregunta confirmación del nombre antes de crearlo.

## Procedimiento
1. Recoge los puntos que le doy sobre lo aprendido hoy (pueden ser pocos, no inventa contenido adicional).
2. Formatea una entrada con fecha de hoy como encabezado.
3. Si el Doc de diario ya existe, añade la entrada al final; si no existe, créalo la primera vez (preguntando el nombre si no está claro).
4. Confirma por chat que la entrada se añadió, con un resumen de una línea de lo que se guardó.

## Salida esperada
Una entrada nueva y fechada en el Google Doc de diario, con contenido real (no genérico) basado en lo que le conté. Se sabe que funcionó si la entrada aparece en el Doc correctamente fechada y formateada.

## Casos especiales
- Si no doy ningún contenido real de "lo aprendido", pregunta en vez de inventar una entrada.
- Si es la primera vez que se usa esta skill y no hay Doc de diario, crea uno nuevo y lo dice explícitamente (no asume que ya existía).
- No reescribe ni borra entradas anteriores del diario — solo añade al final.
